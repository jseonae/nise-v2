# 조사 변천사 화면 작동 안내

[프로젝트 안내](../README.md) · [조사 변천사 데이터 작성 방법](../data/kr/survey_history/README.md)

개발자가 아닌 작업자와 외부 담당자도 읽을 수 있도록 쉬운 말로 정리했습니다. 기준일은 2026-10-28입니다.

## 한눈에 보기

조사 변천사 화면은 **엑셀 파일 하나만 고치면 바뀝니다.** 홈페이지 코드를 고치거나 관리자 화면에 입력할 필요가 없습니다.

쉽게 말하면 엑셀 파일이 **원고**, 홈페이지가 **인쇄기**입니다. 누군가 조사 변천사 페이지를 열 때마다 홈페이지가 서버에 있는 최신 엑셀(원고)을 가져와서 그 내용대로 화면을 그립니다. 그래서 엑셀을 고쳐 서버에 올리면 그다음에 페이지를 여는 사람부터 바로 바뀐 내용을 봅니다.

- 고치는 파일: `survey_history.xlsx` (조사 변천사 엑셀)
- 바뀌는 화면: 조사 변천사 목록 화면(연도 탭과 조사대상자 카드), 상세 화면(조사 문항 표)

## 엑셀 파일 생김새

엑셀 아래쪽 시트 탭 하나가 화면의 연도 탭 하나입니다. 시트 이름이 곧 연도입니다.

| 시트 이름 | 무엇인가 | 화면에 나오나 |
| --- | --- | --- |
| 작성 방법 | 엑셀 적는 법 안내 | 안 나옴 |
| 2026, 2023, 2020 … 2008 | 그해 조사 내용 | 나옴 (연도 탭 하나씩) |
| 새 연도 양식 | 새 연도를 만들 때 복사하는 빈 양식 | 안 나옴 |

이름이 숫자 4자리(연도)인 시트만 화면에 쓰입니다.

연도 시트 하나는 위아래 두 부분으로 나뉩니다.

- **위쪽 — ■ 기본 정보:** 그해 조사의 이름표입니다. 제 몇 차인지, 공개할지, 조사 부분 목록, 출처 등을 적습니다. 목록 화면 맨 위 개요에 나옵니다.
- **아래쪽 — ■ 조사 문항:** 엑셀 한 줄이 상세 화면 표의 한 줄입니다. 묶음 · 조사대상자 · 영역 · 세부 조사 문항 · 문항수를 모든 줄에 빠짐없이 적습니다.

## 화면에 나오기까지

방문자가 조사 변천사 페이지를 열면, 눈 깜빡할 사이에 아래 순서로 화면이 만들어집니다.

1. **엑셀 가져오기** — 홈페이지가 서버에 있는 엑셀 파일을 내려받습니다. 매번 새로 받기 때문에 방금 올린 파일이 바로 쓰입니다.
2. **연도 시트 고르기** — 시트 이름이 연도인 것만 고릅니다. ‘작성 방법’, ‘새 연도 양식’은 건너뜁니다.
3. **시트 읽기** — 위쪽 기본 정보와 아래쪽 조사 문항 표를 읽습니다. 위아래로 이어진 같은 조사대상자의 줄들은 카드 하나로 묶습니다.
4. **잘못 적힌 곳 검사** — 문항수 칸에 글자가 있거나 필수 칸이 비어 있는지 확인합니다. 문제가 있으면 화면을 그리지 않고 안내 문구를 보여 줍니다.
5. **계산하기** — 문항 수 합계처럼 엑셀에 적지 않는 값을 계산합니다. (아래 ‘자동으로 채워지는 것’)
6. **화면 그리기** — 목록 화면에는 연도 탭과 카드를, 상세 화면에는 조사 문항 표를 그립니다.

처음 목록을 열면 공개된 연도 중 가장 최근 탭이 열려 있습니다. ‘예정’으로 적은 연도는 탭만 보이고 눌리지 않습니다.

## 자동으로 채워지는 것

아래 값은 엑셀에 적지 않습니다. 홈페이지가 엑셀 내용을 보고 알아서 계산합니다.

| 화면에 나오는 것 | 어떻게 정해지나 |
| --- | --- |
| 조사대상자별 문항 수 | 그 대상자 줄들의 문항수를 더함 |
| 영역 수 | 그 대상자의 줄 수를 셈 |
| 묶음 제목 옆 ‘2종’ | 그 묶음에 든 조사대상자 수를 셈 |
| ‘조사 대상자 8개·영역 50개·총 421문항’ 같은 요약 | 그해 전체를 셈 |
| 상세 화면의 이전글 · 다음글 | 같은 연도 안에서 엑셀 줄 순서대로 |
| 상세 화면 주소 번호 (예 `?id=603`) | 차수 × 100 + 그 연도 안에서 몇 번째 조사대상자인지 |

주소 번호 예시: 2023년(제6차)의 세 번째 조사대상자는 6 × 100 + 3 = **603**입니다.

## 자주 묻는 질문

**엑셀 시트 순서를 바꾸면 화면 탭 순서도 바뀌나요?**
아니요. 화면의 연도 탭은 각 시트에 적은 ‘차수’ 순서(1차, 2차 …)로 나옵니다. 엑셀에서는 보기 편하게 최근 연도를 앞에 두었지만, 어떤 순서로 놓아도 화면은 같습니다.

**새 연도는 어떻게 추가하나요?**
‘새 연도 양식’ 시트를 복사하고 시트 이름을 연도(예 2029)로 바꿉니다. 내용을 채우고 공개 여부를 ‘공개’로 두면 탭이 생깁니다. 홈페이지 코드는 고치지 않습니다.

**아직 준비 중인 연도는요?**
공개 여부를 ‘예정’으로 두면 탭은 보이지만 눌리지 않습니다. 조사 문항 표는 비워 둬도 됩니다.

**엑셀을 잘못 적으면 어떻게 되나요?**
방문자에게는 ‘목록을 불러오지 못했습니다’ 안내만 보입니다. 그래서 운영 서버에 올리기 전에 개발 서버에서 먼저 확인합니다. 목록 주소 끝에 `?check=1`을 붙여 열면 ‘[2023] 15번째 줄 : …’처럼 어느 시트 몇 번째 줄이 문제인지 알려 줍니다.

**바꾼 내용은 언제 화면에 나오나요?**
서버에 엑셀을 올린 뒤 페이지를 여는(또는 새로고침하는) 순간부터 나옵니다. 따로 반영하는 작업은 없습니다.

## 꼭 지킬 것

- **파일 이름은 그대로** — `survey_history.xlsx`, 엑셀(.xlsx) 형식으로 저장합니다. 이름을 바꾸거나 CSV · 암호 걸린 파일로 저장하면 화면이 읽지 못합니다.
- **모든 줄을 빠짐없이** — 묶음 · 조사대상자도 매 줄 적습니다. 셀 병합은 쓰지 않습니다.
- **표 제목 줄은 고치지 않기** — ‘묶음, 조사대상자, 영역 …’ 글자를 바꾸면 화면이 표를 찾지 못합니다.
- **새 조사대상자는 그 연도의 맨 뒤에** — 중간에 끼워 넣거나 순서를 바꾸면 뒤 대상자들의 상세 화면 주소 번호가 바뀝니다. 예전 주소를 공유해 둔 곳이 있으면 다른 화면으로 연결됩니다.
- **비공개 내용은 넣지 않기** — 이 엑셀은 홈페이지 방문자 누구나 내려받을 수 있습니다. 메모 · 숨긴 시트에도 공개하면 안 되는 내용을 넣지 않습니다.
- **올리기 전에 확인** — 개발 서버에서 `?check=1`로 열어 보고, 문제가 없을 때 운영 서버에 올립니다.

## 개발자용 참고

엑셀만 고치는 분은 이 부분을 보지 않아도 됩니다. 저장소(`nise-v2`) 안의 위치입니다.

| 파일 | 하는 일 |
| --- | --- |
| `data/kr/survey_history/survey_history.xlsx` | 데이터 원본 (사람이 고치는 유일한 파일) |
| `data/kr/survey_history/README.md` | 작성 · 확인 절차 상세 안내 |
| `js/common/cm-xlsx.js` | 브라우저에서 엑셀 파일을 풀어 시트 · 줄 · 칸 값을 꺼냄 (외부 라이브러리 없음) |
| `js/kr/survey-history.js` | 연도 시트 해석 · 검사 · 자동 계산 · 목록과 상세 화면 그리기 |
| `html/kr/stat/survey_history_list.html` | 목록 화면 틀 |
| `html/kr/stat/survey_history_view.html` | 상세 화면 틀 (주소 `?id=번호`) |

DB · 관리자 화면 · 변환 작업이 없는 정적 페이지입니다. 스크립트를 고치면 두 HTML의 스크립트 주소 뒤 `?v=` 날짜를 함께 바꿔 브라우저가 예전 파일을 쓰지 않게 합니다.
