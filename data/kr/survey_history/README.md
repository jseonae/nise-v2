# 조사 변천사 데이터

[프로젝트 안내](../../../README.md) · [개발·유지보수](../../../docs/maintenance.md)

프로젝트 경로는 저장소 루트 기준입니다.

조사 변천사 화면(목록 · 상세)은 이 폴더의 **엑셀 파일 하나**를 읽어서 그립니다.
엑셀 파일만 바꿔 올리면 화면이 바뀝니다. 따로 변환하거나 실행할 것이 없습니다.

| 무엇 | 어디 |
|---|---|
| 데이터(엑셀) | `data/kr/survey_history/survey_history.xlsx` |
| 화면 | `html/kr/stat/survey_history_list.html`, `html/kr/stat/survey_history_view.html?id=번호` |
| 엑셀을 읽는 스크립트 | `js/common/cm-xlsx.js` |
| 화면을 그리는 스크립트 | `js/kr/survey-history.js` |

## 내용을 바꾸는 순서

1. `survey_history.xlsx` 를 내려받아 고치고 저장합니다. **파일 이름과 형식(.xlsx)은 그대로** 둡니다.
2. **개발 서버**에 올린 뒤 아래 주소로 확인합니다.
   - 목록 : `…/html/kr/stat/survey_history_list.html?check=1`
   - 주소 끝의 `?check=1` 은 확인용입니다. 엑셀에 잘못 적힌 곳이 있으면 `[시트 이름(연도)] 몇 번째 줄 : 무엇이 문제` 인지 화면에 알려 줍니다.
3. 문제가 없으면 같은 파일을 **운영 서버**의 같은 위치에 올립니다. 올리는 즉시 반영됩니다.

> 엑셀에 잘못 적힌 곳이 있으면 일반 방문자에게는 화면 대신 "목록을 불러오지 못했습니다" 안내만 보입니다.
> 그래서 운영 서버에 올리기 전에 꼭 개발 서버에서 `?check=1` 로 확인해 주세요.

## 엑셀 틀 : 시트 하나 = 연도(탭) 하나

| 시트 | 용도 |
|---|---|
| **[작성 방법]** | 사람이 읽는 안내. 화면에 쓰지 않습니다. |
| **[2026] · [2023] · … · [2008]** | 연도별 내용. **시트 이름이 연도**입니다. 최근 연도가 앞에 오도록 놓았습니다. 시트 순서를 바꿔도 화면에는 연도 순서로 나옵니다. |
| **[새 연도 양식]** | 새 연도를 추가할 때 복사해서 쓰는 빈 양식. 화면에 쓰지 않습니다. |

[작성 방법] · [새 연도 양식]이 아닌데 이름이 연도(숫자 4자리)가 아닌 시트(예 `2029년`, `2023 (2)`)가 있으면 오류입니다. **연도 시트는 숨기지 않습니다.** 숨겨도 화면에 나오므로 오류로 멈춥니다. 화면에서 빼려면 공개 여부를 `예정`으로 하거나 시트를 지웁니다. 한 해의 내용을 고칠 때는 그 연도 시트 하나만 열면 됩니다.

### 연도 시트 위쪽 : ■ 기본 정보 (탭 · 목록 개요)

A칸에 항목 이름, B칸에 값을 적습니다. C칸에는 적지 않습니다(값이 있으면 오류). 오른쪽 D칸의 회색 안내는 읽지 않는 메모 칸입니다.

**차수 · 공개 여부 · 기준 · 영역 이름 · 묶음 단위 · 문항 단위는 비워 둘 수 없습니다.** 차수는 연도가 늦을수록 커야 합니다.

| 항목 | 적는 값 |
|---|---|
| 차수 | 제 몇 차인지 숫자만(예 `6`). 상세 주소 번호(차수×100+순서)에 쓰입니다. |
| 공개 여부 | `공개` 또는 `예정` (고르기 목록). 예정이면 탭만 보이고 눌리지 않으며, 아래 표를 비워 둬도 됩니다. |
| 기준 | `대상자` 또는 `부문` (고르기 목록). 개요 문구가 "조사 대상자 8개" / "조사 부문 5개" 로 바뀝니다. |
| 영역 이름 | 상세 표 첫 칸의 제목 (보통 `영역`, 2008년은 `조사요소`) |
| 묶음 단위 | 목록의 묶음 제목 옆 "2종" 의 단위 (보통 `종`) |
| 문항 단위 | `문항` 또는 `항목` (고르기 목록) |
| 조사 부분 | 개요에 나오는 목록. **한 줄에 하나씩** 적습니다. 줄이 모자라면 그 아래에 줄을 넣고 A칸은 비운 채 B칸에 이어서 적습니다. |
| 안내 | 개요 아래 ※ 문구. 없으면 비워 둡니다. |
| 출처 | 자료 출처 |

### 연도 시트 아래쪽 : ■ 조사 문항 (한 줄 = 상세 화면 표의 한 줄)

| 묶음 | 조사대상자 | 영역 | 세부 조사 문항 | 문항수 | 주석 | 대상자 전체 문항수 |
|---|---|---|---|---|---|---|
| 보호자용 면접 조사 문항 | 특수교육대상자 보호자 | 일반사항 | 거주형태(2), … | 3 | | |
| 보호자용 면접 조사 문항 | 특수교육대상자 보호자 | 교육 | 취학유예·유예 경험(3), … | 23 | | |
| 보호자용 면접 조사 문항 | 장애영아 보호자 | 일반사항 | 거주형태(2) | 2 | | |
| 관리자 및 교사용 온라인 조사 문항 | 특수학교 관리자 | 일반사항 | 방과후학교 참여 현황, … | 5 | | |

- **묶음 · 조사대상자도 모든 줄에 빠짐없이 적습니다.** 엑셀 필터는 빈칸을 고르지 못하기 때문입니다. 위아래로 이어진 같은 조사대상자는 한 대상자로 묶여 화면에 나옵니다.
- 표 제목 줄에 필터(▼)가 걸려 있어 묶음 · 조사대상자 · 영역별로 골라 볼 수 있습니다. **셀 병합은 쓰지 않습니다.**
- 묶음이 있는 연도는 모든 줄에 묶음을 적고, 묶음이 없는 연도는 모든 줄을 비웁니다.
- **같은 묶음 · 조사대상자의 줄은 붙여서 적습니다.** 떨어진 곳에 다시 나오면 오류입니다. 엑셀 정렬 기능은 쓰지 않고, 보기만 할 때는 필터를 씁니다.
- 문항수 · 대상자 전체 문항수는 0 이상의 숫자만 적습니다. 글자 칸(묶음 · 조사대상자 · 영역 · 세부 조사 문항 · 주석)에는 텍스트 서식이 걸려 있어 `3-1` 같은 값이 날짜로 바뀌지 않습니다.
- 표 제목이 없는 칸(오른쪽)에 메모를 적거나, 제목 줄에 다른 칸(비고 등)을 더 만들지 않습니다.
- **묶음** : 목록에서 카드를 묶는 제목. 묶음이 없는 연도는 비워 둡니다.
- **조사대상자** : 목록의 카드 제목이자 상세 화면 제목.
- **영역 / 세부 조사 문항 / 문항수 / 주석** : 상세 화면 표에 그대로 나옵니다. 영역 이름이 없으면 `-` 를 적습니다.
- **대상자 전체 문항수** : 영역별 문항수를 모를 때만, 그 대상자의 첫 줄에 전체 수를 적습니다. 모든 줄에 같은 수를 적어도 됩니다. (지금 2011 · 2014 · 2017년이 이 경우)
- **줄 순서가 화면에 나오는 순서**입니다. 빈 줄은 무시됩니다.
- 대상자가 바뀌는 줄의 굵은 윗선은 보기 편하게 그린 것입니다. 지우거나 바꿔도 화면에는 영향이 없습니다.
- A칸이 `■` 로 시작하는 줄(구역 제목)은 읽지 않습니다. 표 제목 줄(묶음 · 조사대상자 · 영역 …)의 글자는 바꾸지 않습니다. 열 순서는 바뀌어도 됩니다.

## 잘못 적힌 곳 (오류로 멈추는 경우)

잘못 적힌 곳은 **추측해서 채우거나 건너뛰지 않고 오류로 멈춥니다.** 오류는 엑셀을 저장할 때가 아니라 화면이 엑셀을 읽을 때 나옵니다.
방문자에게는 "목록을 불러오지 못했습니다"만 보이고, 목록 주소 끝에 `?check=1`을 붙이면 `[2023] 15번째 줄 : …`처럼 원인이 보입니다.

| 경우 | 예 |
|---|---|
| 시트 | 연도가 아닌 시트 이름, 숨긴 연도 시트, 같은 연도 시트 두 개 |
| 기본 정보 | 필수 항목 비움, C칸에 값, 정해지지 않은 항목 이름, 고르기 목록 밖의 값, 차수 겹침 · 0 이하 · 연도 순서와 어긋남 |
| 조사 문항 표 | 제목 줄의 칸 이름이 바뀌거나 빠짐 · 더 있음, 제목이 없는 칸에 값 |
| 줄 | 조사대상자 · 영역 비움, 묶음 일부만 비움, 같은 묶음 · 대상자가 떨어져 다시 나옴(정렬로 섞임, 중간 줄 오타) |
| 숫자 | 문항수에 글자 · 소수 · 음수 · 전각 숫자, 대상자 전체 문항수가 두 가지이거나 합계와 다름 |
| 글자 칸 | 숫자로 저장된 값 (엑셀이 `3-1`을 날짜로 바꾼 경우 등) |
| 연도 | 공개인데 조사 문항 표가 비어 있음 |

코드로 막을 수 없는 것 : 대상자 이름이 **마지막 줄만** 오타이면 새 대상자로 읽힙니다. 올리기 전에 `?check=1` 화면에서 대상자 수 · 문항 수를 눈으로 확인합니다.

## 자동으로 계산되는 것 (엑셀에 적지 않음)

- 대상자별 문항 수 합계, 영역 수, 묶음의 `2종`, 요약 문구(`조사 대상자 8개·영역 50개·총 421문항`), 이전글 · 다음글
- 상세 주소 번호(`?id=603`) : 차수×100 + 그 연도 안에서의 순서.
  **대상자 순서를 바꾸거나 중간에 끼워 넣으면 그 뒤 대상자의 주소가 바뀝니다.** 새 대상자는 되도록 그 연도의 맨 뒤에 추가하세요.

## 새 연도(차수) 추가

1. [새 연도 양식] 시트를 복사(시트 탭 오른쪽 클릭 → 이동/복사 → 복사본 만들기)하고 시트 이름을 연도(예 `2029`)로 바꿉니다.
   복사한 시트는 [작성 방법] 바로 뒤로 옮겨 두면 최근 연도부터 차례로 보입니다. (순서는 화면에 영향 없음)
   그 연도 시트가 이미 `예정`으로 있으면 복사하지 않고 그 시트에 적습니다.
2. 기본 정보와 조사 문항을 적고, 공개 여부를 `공개`로 바꿉니다.
3. 개발 서버에서 `?check=1` 로 확인한 뒤 운영 서버에 올립니다. HTML 은 고치지 않습니다.

## 알아 둘 점

- 방문자의 브라우저가 화면을 열 때마다 이 엑셀 파일을 내려받아 읽습니다. 그래서 **이 엑셀 파일은 누구나 내려받을 수 있습니다.**
  공개하면 안 되는 내용(메모, 숨긴 시트, 작업용 시트 등)은 넣지 않습니다. 이름이 연도가 아닌 시트도 화면에만 안 나올 뿐 파일 안에는 그대로 있습니다.
- 암호가 걸린 엑셀, 옛 형식(.xls), 다른 이름으로 저장한 CSV 는 읽지 못합니다.
- 값은 글자 그대로 읽습니다. 수식은 엑셀이 마지막으로 계산해 둔 값이 쓰입니다.

> 지금 들어 있는 값은 nise2026 프로토타입(조사 변천사 시안)의 데이터를 옮긴 임시 데이터입니다. 확정 자료로 바꿔 주세요.

## 로컬에서 확인

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 [조사 변천사 검증 화면](http://127.0.0.1:8000/html/kr/stat/survey_history_list.html?check=1)을 엽니다. 목록의 연도·대상자·문항 수와 상세 이동을 함께 확인합니다.

`python3 _tools/check_project.py`는 경로·생성 구간·스크립트 문법을 검사합니다. XLSX 내용의 업무 규칙 검사는 브라우저의 `survey-history.js`가 수행하므로, 엑셀 교체 후에는 위 화면을 별도로 확인합니다.
